# Phases

C0 laid the foundations. C1 to C3 are planned and run in order, each when the user starts it: first the `.dcr` on
LibreShockwave, then one program for the client's files, then the JavaScript client.

## Order

1. [C0 Foundations](/phases/c0-foundations.md) — The plan's bundle, listed with every plan, and LibreShockwave's source in the repository as a submodule. **Done.**
2. [C1 The client page on LibreShockwave](/phases/c1-client-page-on-libreshockwave.md) — A signed-in habbo opens the CMS's client page, where the R26 .dcr runs on LibreShockwave with an SSO ticket and connects to the game server, and the .dcr is decompiled into a recent R26 source.
3. [C2 The client's files](/phases/c2-client-files.md) — One program serves the client's files, the .dcr and its casts from a folder outside the binary and the external texts and variables that housekeeping edits, from inside the one binary.
4. [C3 The JavaScript client](/phases/c3-javascript-client.md) — The client page runs the R26 client in vanilla JavaScript, without LibreShockwave or the .dcr.
