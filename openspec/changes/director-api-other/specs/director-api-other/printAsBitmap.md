## printAsBitmap()

**Source**: `docs/drmx2004_scripting_ref.txt` lines 24402-24417

### Usage
```lingo
spriteObjRef.printAsBitmap({targetName, #printingBounds})
spriteObjRef.printAsBitmap({targetName, #printingBounds});
```

### Description
Flash sprite command; functions much like the print command, but works only with
Flash sprites. However, printAsBitmap can be used to print objects containing alpha
channel information.
