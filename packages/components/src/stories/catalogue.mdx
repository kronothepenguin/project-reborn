# Design system catalogue

The design system is one shared set of components for the project's applications. This
catalogue shows every baseline component in every documented state, each with a short note on
when to use it.

**Button** now carries the `surface` theme: a base colour with a lighter raised face, a 2px
black border, and a 4px radius, with visible hover, focus, active, and disabled states. It has
four variants — **Default**, **Green**, **Dark**, and **Red** — each shown as its own catalogue
entry. In the surface theme it uses 4px vertical padding and 12px bold text, and its two sizes —
**Wide** (16px horizontal padding, the default) and **Compact** (8px) — each have their own
catalogue entry. The remaining components are still functional and unstyled; their variants and
the `flat` theme arrive in a later slice.

**Paper** now carries the `surface` theme too: a flat surface with no elevation — a 1px `black/20`
border, an 8px radius, and a 3px `black/20` bottom border. It has nine variants — **Default**,
**Login**, **Gray**, **Black**, **HC**, **Yellow**, **Light Green**, **Blue**, and **Room
Pattern** — each shown as its own catalogue entry; a variant changes only the background colour,
and **Room Pattern** is a flat background, not an image.
