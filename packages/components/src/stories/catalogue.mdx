# Design system catalogue

The design system is one shared set of components for the project's applications. This
catalogue shows every baseline component in every documented state, each with a short note on
when to use it. Components are functional and unstyled in this first slice; variants and the
look & feel arrive in a later slice.

## Components

Browse **Components** in the sidebar. Every baseline component appears with one story per
documented state:

- **Button**, **Link**, **Paper**, **Card**
- **Input**, **Form field**
- **Menu**, **Menu item**
- **Tabs**, **Tab**, **Tab panel**
- **Dialog**
