# Decision

- The shared inventory is a new page, `/account/furni`, in the account settings' menu, after Habbos, and built like that
  page.
- It lists each furni by name, with how many of it there are and a Take button.

# Context

HoloCMS has no such page. Offered an account page or a box on the Habbos page, the user chose "An account page, 'Furni'
(Recommended)": "A new page /account/furni in the account settings menu, after 'Habbos', built like that page: a list
with each furni's name, how many of it there are, and a Take button. Example: after archiving a habbo you open Account
settings, Furni, and see its 12 furni there."
