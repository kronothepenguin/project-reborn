# Decisions

- [0001 Plans are feature slices in one bundle](/decisions/reborn/0001-plans-are-feature-slices-in-one-bundle.md) — New work is planned in plans/reborn by feature slice, each across every project it touches, with one folder of tasks; the bundles holo-port, server and client stay as history.
- [0002 A coordinator shares tasks with sub-agents and merges in batches](/decisions/reborn/0002-a-coordinator-shares-tasks-and-merges-in-batches.md) — Tasks live in one folder and name the packages they change; a task is taken by creating its worktree; sub-agents work tasks in parallel and never decide or merge; the coordinating session merges ready branches together after one run of the gates.
- [0003 reborn runs the hotel in one process, and the separate programs stay](/decisions/reborn/0003-reborn-runs-the-hotel-in-one-process.md) — apps/reborn runs the installer, the site, housekeeping and the game server in one process on one mux with one database handle, its logic in packages/reborn and its address in a new reborn section of config.json; the standalone runners stay, for work on one program and for testing how programs talk.
- [0004 Inside reborn the installer lives under /installer/, moves the hotel to the address it is given, and goes once installed](/decisions/reborn/0004-the-installer-inside-reborn.md) — reborn serves the installer under /installer/ until an administrator exists, asks one host and port for the whole site and moves its listener to them at once, and answers 404 under /installer/ once installed; run alone the installer keeps today's form; the done page goes.
- [0005 The game hears of live changes through services](/decisions/reborn/0005-the-game-hears-live-changes-through-services.md) — Changes the game must show at once reach it through small contracts in packages/services, injected into the apps after New; reborn passes in-memory implementations, programs run apart call the game's /api/ over HTTP with a secret; calls carry ids only and store nothing.
- [0006 Every program reads settings from the store, and nothing refreshes](/decisions/reborn/0006-settings-are-read-from-the-store.md) — The CMS, housekeeping, the installer, auth and the game server read each setting with a sqlc query through packages/settings, which returns the declared default when there is no row; virtual/settings and every refresh go, and the game checks for waiting database updates on use.
- [0007 reborn stops in order](/decisions/reborn/0007-reborn-stops-in-order.md) — On Ctrl-C or SIGTERM reborn stops taking requests, logs every player out and closes the game's listeners, stops the scheduled tasks and closes the database, with new Shutdown and Stop functions in the game server and the scheduler.
- [0008 Releases ship reborn and the four separate programs](/decisions/reborn/0008-releases-ship-reborn-and-the-separate-programs.md) — Each release archive holds reborn and the standalone CMS, housekeeping, installer and game server, so that an administrator chooses one binary or several.
- [0009 reborn's dev runner proxies one Astro dev server for every site, after a spike proves it](/decisions/reborn/0009-one-dev-server-for-reborn.md) — A dev-only Astro project in packages/reborn serves the CMS's pages at /, housekeeping's at /housekeeping/ and the installer's at /installer/ from one dev server, so that reborn-dev proxies it as the standalone dev runners proxy theirs; a spike proves it first.
- [0010 Slices follow the hotel's own features, and habbos comes first](/decisions/reborn/0010-slices-follow-the-hotels-features.md) — The economy and club are separate slices, furni with its catalogue is furnis, friends is the messenger, and habbos, rooms and navigator are slices of their own; the habbos slice is the first feature built, end to end from the site to the client.
- [0011 No Habbo files in the repository; a tool fetches them](/decisions/reborn/0011-no-habbo-files-in-the-repository.md) — Sulake's files, from the client's .dcr and casts to images and decompiled scripts, leave the repository and its history; a tool fetches them, pinned, into ignored folders, and the programs serve them from disk; LibreShockwave stays a submodule and its player is built from it.
- [0012 The client page ports Holo's, with LibreShockwave in place of Adobe's plugin](/decisions/reborn/0012-the-client-page-ports-holos-on-libreshockwave.md) — The CMS serves Holo's client.php, clientutils.php and unloadclient.php ported exactly, with the R26 .dcr on LibreShockwave; the game's addresses come from config.json, the external texts and variables from the client files, and Holo's other client settings become settings; a spike proves the client logs in first.
- [0013 A habbo's look and motto reach the game at once, from wherever they change](/decisions/reborn/0013-a-habbos-look-and-motto-reach-the-game-at-once.md) — The site's looks and motto pages and housekeeping's habbo editor tell the game through the Habbos service, and the game shows the habbo's new look and motto to it and to its room at once.
- [0014 The backend template of tools/create keeps its HTTP server](/decisions/reborn/0014-the-backend-template-keeps-its-http-server.md) — make create template=backend still generates a package with a Mount, a router and an HTTP server, though the game server no longer has one.
