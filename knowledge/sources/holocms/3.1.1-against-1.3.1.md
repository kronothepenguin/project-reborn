# How to read this

- `holocms/` is HoloCMS 3.1.1 in `source/holocms`. `holocms-1.3.1/` is HoloCMS 1.3.1 in `source/holocms-1.3.1`. A
  citation without a folder is in 3.1.1.
- "The site" is the running 3.1.1 on `http://localhost:11300`, seen on 2026-11-24 as `admin`.
- Every page of the port follows 1.3.1 today ([the two versions](/sources/holocms/versions.md)).

# What kind of copy 3.1.1 is

- It is one hotel's edited copy, not a clean release. It names "Bobble Hotel" in the motto default (`me.php:101`), the
  landing intro (`templates/login/column1.php:36-48`), the welcome page (`welcome.php:70`, `:110`), the staff page
  (`staff.php:202`) and the footer ("Edited by Cody", `templates/community/footer.php:69`). The landing links two
  fan-site buttons (`index.php:241`).
- `group_forum.php:627-652` holds Dutch dialogs ("Groepsinstellingen", "Kamersettings").
- `groups.php` is a file of another CMS, PHPRetro (`groups.php:11-16`). It requires files the tree lacks; the site
  answers with a fatal error.
- Pages serve `charset=utf-8` while the files are Latin-1 (`templates/community/subheader.php:22`).
- Many features ship broken. Each section names the breaks it found.

# Changes on every page

- `addslashes` and `stripslashes` become `FilterText` and `HoloText` (`core.php:682-694`). `FilterText` escapes HTML
  before it stores text, so stored text holds entities.
- `session_is_registered` becomes `isset($_SESSION[...])` (`core.php:155`, `:299`, `:412`, `:605`).
- A page may set `$allow_guests` and let visitors in when the setting `allow-guests` is 1 (`includes/session.php:16-22`).
- The stylesheets of the homes, the minimail and the groups load from `./web-gallery` instead of Habbo's servers
  (`templates/community/subheader.php:53-59`, `:103`). Every page links an RSS feed (`:39`).
- The columns `#column1`, `#column2` and `#column3` take their widths on every page, not only on `body#home`
  (`web-gallery/v2/styles/style.css:244-270`).
- The bottom of the community layout draws the banners column for every page, except the forum and pages that set
  `$noads` (`templates/community/footer.php:33-58`). In 1.3.1 `me.php` drew it alone (`holocms-1.3.1/me.php:663-692`).
- BBCode gains `[habbo=id]`, `[room=id]` and `[group=id]` links (`core.php:231-251`).
- New box colours in `style.css`: `welcome` #f66200, the invitation box #559EDC, `pixelblue` #0046A8, `pixelgreen`
  #20C124, `pixellightblue` #6DCDF6, `pixeldarkblue` #168291 (`style.css:179-182`, `:3026-3027`, `:3204-3233`).

# Navigation

- The Credits tab gains a sub-tab "Collectables" (`templates/community/header.php:212-233`). "Habbo Club" reads
  "<shortname> Club".
- The test of the Credits sub-navigation is an assignment (`$pageid = "collectables"`, `header.php:212`), so every
  page the earlier tests miss shows it. The staff page shows it on the site.
- The Housekeeping tab links `./housekeeping/` (`header.php:124`). The counter reads "N <shortname>s online now"
  (`:128`).
- The quick menus (My Friends, My Groups, My Rooms) and the search stay. The friends menu now finds a friend on either
  side of `messenger_friendships` (`habblet/quickmenu.php:19`, `:38-42`).

## Against the emulator's dumps

`source/holoemu` holds `database.sql` (a dump of 11 October 2008) and `holodb.sql` (with a copy in `Resources/`).

- Both hold every `cms_*` table of 3.1.1 except `cms_verify`, with the same columns. Both hold `room_votes`,
  `groups_details.pane`, `.topics` and `rooms.showname`.
- `users`: `database.sql` lacks `newsletter` and `email_verified`. `holodb.sql` lacks those two and `gift`, `sort`,
  `roomid`, `lastgift` and `visibility`. Both keep `screen` and `rea`.
- `events` is in `holodb.sql:469` only. `database.sql` has `applications` and `ranks`; `holodb.sql` has `events`,
  `cms_posts`, `cms_threads`, `diving_score` and `wobble_squabble`.

# Breaks seen on the site

- A home with no stickers stops at "Field 'data' doesn't have a default value": the first widget's insert fails
  (`user_profile.php:760`).
- `groups.php` stops at a fatal error. The join and leave links of a group point to root files 3.1.1 moved
  (`group_profile.php:132-135`).
- The staff page shows blank headings and the Credits sub-navigation.
- The RSS descriptions are empty.

# Questions for the user

1. Which version does a page ported before today follow? I recommend 3.1.1 where it changes what a visitor sees
   (Me, Community, Credits, homes, groups), page by page, each as its own task.
2. 3.1.1 carries one hotel's texts ("Bobble Hotel", "Edited by Cody", Dutch dialogs, fan-site buttons). I recommend
   the general text of 1.3.1 wherever 3.1.1 names that hotel.
3. Where a 3.1.1 feature ships broken (the e-mail check, the recommended editor, the home's first widget), does the
   port build what it means or skip it? I recommend what it means, each listed in
   [the differences](/sources/holocms/differences.md).
4. Which features does the port take, and in what order? I recommend first the boxes of the pages already ported
   (Me's Recommended, Community's Rooms and Groups tabs, Credits' Refer Options and Leaderboard), then group forums,
   the home widgets, the minimail, friend requests and management, invitations, collectables and the FAQ.
5. Which does it leave out? I recommend the badge and furni shop, `groups.php`, `invite.php`, `restart.php`, the
   application forms, and the newsletter's raw SQL condition.
6. Events, starter rooms and the minimail's report need the game server's data (`events`, `rooms`, `furniture`). Do
   they wait for the server? I recommend they wait, as [0013](/decisions/holo-port/0013-defer-game-server-features.md)
   decides for 1.3.1.
7. 3.1.1 hashes passwords with sha1. I recommend the port keeps argon2id
   ([0005](/decisions/holo-port/0005-argon2id-passwords.md)).
8. 3.1.1 asks the password again before the client when the ticket is spent. Does the client page take that step? I
   recommend the [client feature](/features/client/spec.md) decides it.
9. Do the new housekeeping pages keep 3.1.1's access, open to rank 6? I recommend each gets its own attribute, as
   [0014](/decisions/holo-port/0014-attribute-based-access.md) does.
